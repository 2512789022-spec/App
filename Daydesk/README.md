# 每日计划 · 手机 App

由 **DayDesk（桌面日程平台）** 改编的手机应用：不做日程编排，只做**每日任务计划**——列出当天要做的事，做完一件打钩一件（✓ + 划线）。

提供两种形态，功能与界面完全一致：

| 形态 | 文件 | 说明 |
| --- | --- | --- |
| **安卓 APK**（推荐） | `每日计划-v2.2.apk` | 专注计时改为秒表模式（开始/结束直接计实际时长）|
| 旧版本 | `每日计划-v1.1.apk` ~ `v2.1.apk` | 历史版本存档 |
| 网页版（备用） | `index.html` | 单文件、零依赖、零构建、完全离线（始终跟随最新设计） |

## 安卓 APK 安装

1. 把 `每日计划-v2.2.apk` 发到手机（微信文件传输助手 / QQ / 数据线 / 网盘均可）。
2. 在手机上点开安装。已装过旧版的直接覆盖升级，数据全部保留。
3. 系统提示「未知来源应用」时，允许该来源安装即可。
4. 支持 Android 5.0 ~ 15+（minSdk 21，targetSdk 34），v1+v2+v3 签名齐全。
5. 深浅色主题自动跟随系统；「导出备份」经 MediaStore 写入系统下载目录，无需存储权限。

## v2.0 提醒时间·滚动选择

## v1.9 通知与时间选择

- **通知升级为横幅弹出**（高优先级渠道），到点直接在屏幕上方弹出，不再只是安静躺在通知栏
- 设置里新增「**发送测试通知**」：一键验证通知链路是否通畅，排查"收不到"问题
- 开启提醒时明确提示**下次提醒时间**（今天/明天 几点）；Android 12+ 未授权精确闹钟时自动引导授权
- **时间选择全面弃用系统轮盘**：提醒时间和长期任务打卡时段改为点选式时间网格（每 30 分钟一档，48 档），打卡时段支持「全天（清除时段）」一键清除

## v1.8 每日提醒

- 设置中新增「**每日提醒**」：开关 + 时间（默认 21:30）
- 到点弹出**系统通知**，内容是当天还没完成的任务清单（含逾期未完成的）；任务都完成时通知「今日任务已全部完成 ✓」；若只有长期任务没打卡，也会一并提醒
- 通知数据实时同步：每次任务变化都会更新给原生侧，通知内容始终是最新状态
- 支持开机自动重排提醒；Android 13+ 首次开启时请求通知权限；精确闹钟未授权时自动降级为分锺级误差
- 网页版兜底：页面打开时到点用页内提示代替通知
- ⚠️ 小米/华为等国产系统请在系统设置中允许本应用「后台运行/自启动」，否则息屏后通知可能延迟

## v1.7 长期任务·时间段制

- 「重置周期」升级为**时间段设置**：**开始/结束日期**（不填结束 = 长期有效）+ **每日打卡时段**（不填 = 全天可打卡）
- 任务状态自动判定：**未开始**（未到开始日期）/ **进行中** / **已结束**，标签显示在任务行上
- 时段外的打卡圆圈置灰禁用；支持跨零点时段（如 22:00~06:00）
- 连续天数、累计次数照常统计；旧版「周期」数据自动迁移为起止日期

## v1.6 长期任务

- 底部标签栏新增「**长期**」页：与每日任务分开管理的长期/习惯型任务
- 每条任务可选**重置周期**：每天（每日重新打卡）/ 每周（每周一清零）/ 不重置（打钩后保持完成）
- 每条显示：重置周期、**连续打卡天数/周数**（今天没打卡不断签）、**累计次数**、备注
- 在长期页底部输入框直接添加；点任务可改标题、备注、周期或删除；打卡有震动反馈
- 长期任务随备份一起导出/导入（兼容旧备份文件）

## 数据说明

- 数据保存在**手机浏览器本地**（localStorage，键 `dayplan.v1`），不上传任何服务器。
- **换手机或清除浏览器数据会丢失**，请定期在「设置 → 导出备份」。
- 任务字段与 DayDesk 的任务模型对齐（`title / date / priority / done / completedAt`），备份 JSON 可直接阅读或再加工。

## 数据与初始状态

- **App 首次打开是空白列表**，没有任何预置任务，直接从底部输入框添加即可。
- v1.0 内置过一批演示任务（提取自 daydesk 数据）；升级到 v1.1 及以上会**自动清除**这批演示任务，自己添加的任务不受影响。
- 数据保存在手机本地（APK 为应用私有目录，网页版为浏览器 localStorage），不上传任何服务器。
- 换手机或清除应用数据会丢失，请定期在「设置 → 导出备份」。
- 任务字段与 DayDesk 的任务模型对齐（`title / date / priority / done / completedAt`），备份 JSON 可直接阅读或再加工。

> 历史说明：`extract-seed.mjs` 曾从 DayDesk 的 daydesk 备份（`.daydesk-verify/data/backups/auto/auto-20261022-224940.json`，源文件夹只读）提取过 17 条真实事项作为演示数据，现保留脚本备查，App 默认不再注入。如需恢复演示数据：`node extract-seed.mjs && node inject-seed.mjs && node build-apk.mjs`。

## APK 构建（android-build/）

无 Gradle 手工构建链：`aapt2 compile/link → javac → d8 → 注入 dex → zipalign → apksigner`。
构建在 ASCII 临时目录进行（aapt2 不支持中文路径），成品拷回上级目录。

```bash
cd android-build
node download-tools.mjs   # 首次：下载 build-tools r34 + platform-34（约 120MB）
node get-r8.mjs           # 首次：下载稳定版 d8（build-tools 34 自带的 8.2.2-dev 有崩溃 bug）
node gen-icons.mjs        # 重新生成应用图标（克莱因蓝 + 白色对勾）
node build-apk.mjs        # 构建 → ../每日计划-v2.2.apk
```

环境要求：JDK（keytool 用完整 JDK 路径 `E:\HMCL\JAVA22`，javapath 里没有 keytool）。
签名密钥 `android-build/dayplan.keystore` 请妥善保存，升级安装必须用同一密钥签名。
